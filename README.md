# Кто выбирает, когда выбираю я?

Прототип интерактивного лонгрида об интерфейсе и распределении инициативы между человеком и системой.

**История 1 — пешеходный маршрут.** Читатель формулирует намерение, карта строит самый быстрый путь, затем читатель сам просит учесть своё желание и сравнивает варианты.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер в папке проекта:

```bash
python3 -m http.server 8080
```

и откройте http://localhost:8080. Сборка и зависимости не нужны.

## Устройство

- `index.html` — сцены: приглашение, выбор задачи, выбор желания, карта, итог.
- `styles.css` — типографика, интерфейс карты, мобильная версия, `prefers-reduced-motion`.
- `app.js` — данные маршрутов и желаний, состояние, SVG-карта и анимация.

Каждая сцена занимает не меньше экрана. Следующая проявляется после заметной прокрутки или когда читатель проходит шаг — тогда страница сама переходит к ней. Прокрутка не блокируется.

Карта, названия и маршруты условные и заранее подготовленные. Время в пути считается по длине линии: самый быстрый маршрут — 18 минут, остальные — пропорционально длине.
